# Product Requirements Document (PRD)

## Professional Digital Agency Website

**Project Type:** Company / Digital Agency Website
**Target:** Professional Software House / Digital Agency
**Primary Goal:** Generate leads, build trust, showcase expertise, and convert visitors into potential clients.

---

# 1. Product Overview

Website ini merupakan website profesional untuk sebuah **Digital Agency / Software Development Agency** yang menyediakan layanan teknologi untuk bisnis, startup, UMKM, maupun perusahaan.

Website harus memberikan kesan:

* Professional
* Modern
* Premium
* Trustworthy
* Innovative
* Fast
* Clean
* Technology-focused

Website bukan hanya sebagai company profile, tetapi juga sebagai **lead generation platform**.

Pengunjung harus dapat memahami dalam beberapa detik:

1. Agency ini siapa?
2. Apa layanan yang ditawarkan?
3. Apa keunggulannya?
4. Apa saja project yang pernah dibuat?
5. Bagaimana proses kerja?
6. Berapa kisaran harga atau bagaimana cara mendapatkan quotation?
7. Bagaimana cara menghubungi agency?

# 38. AI Agent Development Rules

AI Agent WAJIB mengikuti aturan berikut.

## Rule 1 — Jangan merusak existing code

Sebelum mengubah file:

1. Baca file terlebih dahulu.
2. Pahami struktur existing project.
3. Jangan menghapus functionality yang sudah berjalan.
4. Jangan melakukan rewrite besar tanpa alasan.

---

## Rule 2 — Reusable Components

Jangan membuat component yang sama berulang kali.

Gunakan:

```text
components/
```

untuk reusable UI.

---

## Rule 3 — Data Separation

Content harus dipisahkan dari UI.

Gunakan:

```text
data/
```

untuk data statis.

---

## Rule 4 — Mobile First

Semua component harus dibuat responsive sejak awal.

---

## Rule 5 — TypeScript

Gunakan TypeScript secara konsisten.

Hindari:

```ts
any
```

kecuali benar-benar diperlukan.

---

## Rule 6 — No Fake Data

Jangan membuat:

* Fake clients
* Fake testimonials
* Fake statistics
* Fake project results

Gunakan placeholder yang jelas jika data belum tersedia.

---

## Rule 7 — Performance First

Jangan menambahkan dependency hanya untuk kebutuhan sederhana.

Prioritaskan:

```text
Native CSS
Tailwind
Existing utilities
```

sebelum memasang package baru.

---

## Rule 8 — Accessibility

Semua interactive elements harus dapat digunakan dengan keyboard.

---

## Rule 9 — SEO

Setiap halaman publik harus memiliki:

```text
title
description
OpenGraph
```

---

## Rule 10 — Error Handling

Semua form dan API harus memiliki:

```text
loading
success
error
empty
```

states.
